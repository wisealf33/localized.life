# Localized.life SEO Content Structure

Use this outline for public Localized.life pages so search engines and people see the same clear page story.

## Page Metadata

- Meta title: one concise page-specific title. Put the main page topic first.
- Meta description: one unique summary of what the page helps people do or find.
- Canonical path: use the page's real public URL path.
- Open Graph title and description should match the page intent.

Do not include `Localized.life` at the end of page titles passed to `pageMetadata`. The root layout adds the site name.

## Heading Outline

Use one visible `h1` per page for the main topic.

```text
Meta title
Meta description
Header / navigation

Main content
  h1: page topic
  Body section 1
    h2: major section topic
    h3: cards, listings, subsections, or specific items inside that section
    h4-h6: only when a subsection genuinely needs deeper nesting
  Body section 2
    h2
    h3
  Body section 3
    h2
    h3

Footer
```

## Writing Rules

- The `h1` should match the page's primary search intent.
- `h2` headings should describe major body sections, not visual decoration.
- `h3` headings should name individual cards, categories, listings, or form states inside an `h2` section.
- Avoid keyword stuffing. Use natural local phrases only when the page actually covers them.
- Do not restart each body section with another `h1`; use `h2` for section-level topics.
- Keep visible headings useful for readers first. Google can use the title element, the main visual title, headings, and prominent page text to understand the page.

## Localized Public Page Pattern

```text
title: Local goods, mentor, service, event, sale, or harvest phrase
description: specific thing the page helps people find, submit, map, learn, or request
h1: short visible page name
h2: submit, browse, filter, map, route, or explanation sections
h3: cards, categories, event names, service types, listing names
```
